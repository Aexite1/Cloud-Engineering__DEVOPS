# MERN Web Stack Implementation

This repository documents my hands-on implementation of a **MERN (MongoDB, Express.js, React, Node.js)** web stack. It contains the project documentation, screenshots from the implementation process, and supporting study materials.

## Repository Structure

```text
.
├── images/
├── sideSelfStudy/
├── mern_web_stack_implementation.md
├── Resource.md
└── README.md
```

### 📁 images/

Contains screenshots captured during the step-by-step implementation of the MERN stack.

The screenshots are referenced in the main documentation to provide visual evidence and make each stage easier to follow.

### 📁 sideSelfStudy/

Contains additional study materials and notes used to understand concepts related to the project.

This includes research and learning materials that supported the implementation.

### 📄 MERN_web_stack_implementation.md

The main project documentation.

It provides a detailed, step-by-step explanation of the implementation process, with references to the screenshots in the `images` folder.

It covers the commands, configurations, setup process, and important concepts encountered while building the project.

### 📄 Resource.md

Contains useful code snippets and resources used during the project.

## Project Overview

The purpose of this project was to gain practical experience working with the **MERN stack** and understand how its individual technologies work together to build a web application.

### Technologies Used

- MongoDB
- Express.js
- React
- Node.js
- JavaScript
- Git & GitHub

## Recommended Reading Order

1. Start with `MERN_web_stack_implementation.md`.
2. Follow the screenshots in `images/` alongside the documentation.
3. Refer to `sideSelfStudy/` when additional background information is needed.
4. Check `Resource.md` for useful snippets and supporting resources.
