# LEMP Stack Documentation

This repository documents my hands-on implementation of a **LEMP (Linux, Nginx, MySQL, PHP)** stack. It contains a detailed walkthrough of the installation and configuration process, supporting study materials, and screenshots captured during the project.

## Repository Structure

```
.
├── images/
├── sideSelfStudy/
├── LEMPStack Documentation.md
└── README.md
```

## Folder Descriptions

### 📁 images/

This folder contains the screenshots captured throughout the implementation of the LEMP stack.

The images serve as visual evidence of each step and are referenced throughout the project documentation to make the setup process easier to follow.

---

### 📁 sideSelfStudy/

This folder contains additional study materials and notes that supported the completion of this project.

Contents may include:

- Research notes
- Linux commands and explanations
- Nginx, MySQL, and PHP concepts
- Troubleshooting notes
- External references used during learning

These files complement the project but are not required to understand the main implementation.

---

### 📄 LEMPStack Documentation.md

This Markdown document is the main project documentation.

It provides a complete step-by-step explanation of how the LEMP stack was deployed, including:

- Project objectives
- Installation process
- Configuration steps
- Commands used
- Expected outputs
- Explanations for each stage
- References to screenshots stored in the `images` folder

This document is intended to be read alongside the screenshots for the best learning experience.

---

## Project Overview

The goal of this project was to gain practical experience deploying and configuring a LEMP stack while documenting every stage of the process.

By completing this project, I developed hands-on experience with:

- Linux system administration
- Nginx web server configuration
- MySQL database management
- PHP installation and integration
- Command-line operations
- Technical documentation using Markdown
- Organizing project assets for reproducibility
