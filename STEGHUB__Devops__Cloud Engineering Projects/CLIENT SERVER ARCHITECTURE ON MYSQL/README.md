# Client-Server Architecture with MySQL

This repository documents my hands-on implementation of **client-server architecture using MySQL**. It contains the main project documentation, screenshots from the implementation process, supporting study materials, and useful resources.


### 📁 images/

Contains screenshots captured during the step-by-step implementation of the project.

The screenshots are referenced in the main documentation to provide a visual guide to the different stages of the setup and configuration.

### 📁 sideStudy/

Contains additional study materials and notes used while working on the project.

These materials provide further explanations and background information on concepts related to the implementation.

### 📄 client_server_architecture_ON_MYSQL.md

This is the main project documentation.

It provides a detailed explanation of the client-server architecture and the steps involved in setting up and working with MySQL.

The document includes commands, configurations, explanations, and references to the screenshots in the `images/` folder.

### 📄 resource.md

Contains useful code snippets and supporting resources used during the project.

## Project Overview

The purpose of this project was to gain practical experience with **client-server architecture** and understand how a MySQL database can be used within a server-based application environment.

The project also provided hands-on experience with database configuration, server communication, command-line tools, and technical documentation.
