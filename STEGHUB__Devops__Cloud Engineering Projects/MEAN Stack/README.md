# MEAN Book Register

This repository documents my hands-on implementation of a **MEAN (MongoDB, Express.js, Angular, Node.js)** web application. It contains the main project documentation, screenshots from the implementation process, and supporting study materials.

## Repository Structure

```text
.
├── images/
├── sideSelfStudy/
├── MEAN_Book_Register_rewritten.md
├── resource.md
└── README.md
```

### 📁 images/

Contains screenshots captured during the step-by-step implementation of the MEAN stack project.

The screenshots are referenced in the main documentation to provide a visual guide to the different stages of the project.

### 📁 sideSelfStudy/

Contains additional study materials and notes used while working on the project.

These materials provide further explanations and background information on concepts related to the implementation.

### 📄 MEAN_Book_Register_rewritten.md

This is the main project documentation.

It provides a detailed, step-by-step explanation of the Book Register implementation, including the commands, configurations, setup process, and important concepts encountered during development.

The screenshots in the `images/` folder are used throughout the documentation to support the explanations.

### 📄 resource.md

Contains useful code snippets and supporting resources used during the project.

## Project Overview

The purpose of this project was to gain practical experience working with the **MEAN stack** and understand how its components work together to build a web application.

### Technologies Used

- MongoDB

- Angular
- Node.js
- JavaScript
- Git & GitHub

## Recommended Reading Order

1. Start with `MEAN_Book_Register_rewritten.md`.
