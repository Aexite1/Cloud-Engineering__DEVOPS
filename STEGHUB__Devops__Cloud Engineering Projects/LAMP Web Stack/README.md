# LAMP Project Documentation

This repository contains the complete documentation for the LAMP project, including the implementation process, supporting research, and visual references.

## Repository Structure

```
.
├── IMAGES/
├── sideSelfStudy/
├── LAMP_Report_Documentation.md
└── README.md
```

### 📁 IMAGES

This folder contains the screenshots and images captured throughout the project.

The images are organized in the order they were taken and correspond to the implementation steps described in `LAMP_Report_Documentation.md`. They provide a visual guide for each stage of the project.

---

### 📁 sideSelfStudy

This folder contains supplementary learning materials and notes gathered while completing the project.

These resources include:
- Concepts researched during development
- Commands and configuration references
- Additional documentation
- Notes that helped solve implementation challenges

This folder serves as a personal knowledge base and is not required to follow the main project documentation.

---

### 📄 LAMP_Report_Documentation.md

This Markdown document is the primary project report.

It provides:
- A detailed, step-by-step explanation of the project
- The reasoning behind each step
- Configuration details
- Commands used throughout the implementation
- References to the screenshots stored in the `IMAGES` folder

This document should be read alongside the images for the best understanding of the implementation process.

---

## Purpose

This repository was created to document the complete implementation of the LAMP stack project. It combines written explanations, visual documentation, and supporting research into a single reference that can be used for learning, replication, and future review.

## Recommended Reading Order

1. Read `LAMP_Report_Documentation.md`.
2. View the corresponding screenshots in the `IMAGES` folder as you progress.
3. Refer to the `sideSelfStudy` folder for additional explanations and supporting materials when needed.
